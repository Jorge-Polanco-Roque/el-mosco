# 🪰 一只蚊子与一辆卡车

### *六幕存在主义危机*

你通过完成挑战前进——每一个挑战都让你*亲手感受*危机的一个阶段。

> *前一刻它还在嗡嗡作响。后一刻：什么都没有了。宇宙连眼睛都没眨一下。*

一只蚊子毫无理由地穿过公路。一辆卡车驶过。蚊子不复存在。
那百万分之一秒——一场绝对、荒诞、无人见证、毫无意义的死亡——引爆了我们每个人心中都有的那个问题：
**如果那条生命毫无意义，那我的生命又有什么不同?**

这个项目*就是*那份沉思，被做成了一款游戏。艺术的温柔承担了重量，
让文字不必呐喊。**这份反差，就是作品本身。**

## 🎭 六幕

每个挑战都把它的理念*化为机制*——意义不被解释，而被游玩。

| # | 幕 | 挑战 | 落地的真相 |
|:-:|----|------|------------|
| 0 | **引信** | 在光到来之前救下蚊子 | 设计上不可能。*「如果，你就是那只蚊子呢?」* |
| 1 | **微不足道** | 在数百个一模一样的点中找到*你自己* | *「没有一个是特别的。你也不是。然而，你依旧在这里凝望。」* |
| 2 | **荒诞** | 把石头推上山顶（它总会滚回来） | 加缪:*「向着顶峰的挣扎本身，就足以充实一个人的心。」* |
| 3 | **自由的眩晕** | 选择一扇门——其余的将永远消失 | *「每一个「是」，都是一千个「否」。这就是活着。」* |
| 4 | **向死而生** | 让它活着（它熄灭得比你能维持的更快） | 海德格尔:*「死亡不是敌人。它是画框。」* |
| 5 | **反抗** | 建造些什么——留下你的印记 | *「意义不是被找到的。是被创造的。」* → **「我们必须想象蚊子是幸福的。」** |

## ✨ 特性

- **可爱又残酷的美学** — 漂浮的粉彩团块、漫画描边、小手光标、卡通渲染的 3D。
- **六种互动机制** — 每一幕都是一个各不相同的象征性小游戏。
- **自适应芯片音乐** — 以 A 小调实时合成。随着你不断下沉，低通滤波器逐渐关闭：
  开场明亮，在*死亡*中窒闷，在*反抗*中重新焕发光芒。
- **反应式音效设计** — 蚊子的**电击音**、每次转场的紧张**上升音**，
  以及随机化的**选择音效**，让一切都不重复。
- **零构建、零素材、零追踪** — 一个自包含的 HTML 文件。

## 🎮 操作

| 输入 | 动作 |
|------|------|
| **点击 / 触摸** | 前进 · 互动 · 做出选择 |
| **拖拽** | 推动石头（第 2 幕） |
| **M** | 静音 / 开启音乐 |
| **R** | 复活——从结尾重新开始 |

## 🛠️ 技术栈

- **[three.js](https://threejs.org)** (r160) — 使用 `MeshToonMaterial` 的卡通渲染，反向外壳漫画描边。
- **Web Audio API** — 一个小巧的实时芯片音乐引擎（振荡器、滤波器、程序化音效）。没有音频文件。
- **原生 JS + HTML/CSS** — 单文件有限状态机。无框架，无打包器。

## 🚀 本地运行

无需构建步骤。任意静态服务器均可:

```bash
git clone https://github.com/Jorge-Polanco-Roque/el-mosco.git
cd el-mosco
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 音乐会在你第一次点击时开始（浏览器自动播放策略）。

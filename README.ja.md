> *ついさっきまで羽音を立てていた。次の瞬間には、何もない。宇宙はまばたきひとつしなかった。*

一匹の蚊が、理由もなく幹線道路を横切る。トラックが通り過ぎる。蚊は存在しなくなる。
その百万分の一秒——目撃者も意味もない、絶対的で不条理な死——が、私たちが誰しも抱える問いに火をつける。
**あの命に何の意味もなかったのなら、私の命の何が違うというのか?**

このプロジェクトは、その省察そのものをゲームにしたものです。アートの優しさが重さを引き受けるから、
言葉は叫ばなくてよい。**そのコントラストこそが作品です。**

## 🎭 6つの幕

それぞれの課題は、そのアイデアを*メカニクスとして*体現します。意味は説明されず、プレイされます。

| # | 幕 | 課題 | 突きつけられる真実 |
|:-:|----|------|--------------------|
| 0 | **引き金** | 光が届く前に蚊を救え | 設計上、不可能。*「もし、あなたが蚊だったら?」* |
| 1 | **無意味さ** | 何百もの同じ点の中から*あなた自身*を見つけよ | *「どれも特別ではなかった。あなたも。それでも、あなたはこうして見つめ続けている。」* |
| 2 | **不条理** | 岩を頂上まで運べ（必ず転がり落ちる） | カミュ:*「頂上を目指す闘いそれ自体が、人の心を満たすのに十分だ。」* |
| 3 | **自由のめまい** | 一つの扉を選べ——他は永遠に消える | *「一つの「はい」は、千の「いいえ」だ。それが生きるということ。」* |
| 4 | **死へと向かう存在** | 生かし続けよ（支えきれない速さで消えていく） | ハイデガー:*「死は敵ではない。それは枠だ。」* |
| 5 | **反抗** | 何かを築け——あなたの印を残せ | *「意味は見つけるものではない。作るものだ。」* → **「蚊は幸福だと想像しなければならない。」** |

## ✨ 特長

- **かわいく残酷な美学** — 浮遊するパステルのブロブ、コミック調の輪郭、手のカーソル、セルシェーディングの3D。
- **6つのインタラクティブなメカニクス** — 各幕がそれぞれ異なる象徴的なミニゲーム。
- **適応型チップチューン** — イ短調でライブ合成。降りていくほどローパスフィルターが閉じ、
  冒頭は明るく、*死*ではくぐもり、*反抗*で再び輝きます。
- **反応するサウンドデザイン** — 蚊の**ザップ音**、各遷移での緊張の**ライザー**、
  そして繰り返さないためのランダムな**選択SE**。
- **ビルド不要・アセット不要・トラッキングなし** — 自己完結した1つのHTMLファイル。

## 🎮 操作

| 入力 | 動作 |
|------|------|
| **クリック / タップ** | 進む・操作する・選ぶ |
| **ドラッグ** | 岩を押す（第2幕） |
| **M** | 音楽のミュート / 解除 |
| **R** | リバイブ——最後からやり直す |

## 🛠️ 技術スタック

- **[three.js](https://threejs.org)** (r160) — `MeshToonMaterial` によるセルシェーディング、反転ハルによるコミック輪郭。
- **Web Audio API** — 小さなライブ・チップチューン・エンジン（オシレーター、フィルター、手続き的SE）。音声ファイルなし。
- **バニラ JS + HTML/CSS** — 1ファイルの有限状態機械。フレームワークなし、バンドラーなし。

## 🚀 ローカルで実行

ビルド手順は不要。任意の静的サーバーで動きます:

```bash
git clone https://github.com/Jorge-Polanco-Roque/el-mosco.git
cd el-mosco
python3 -m http.server 8000
# http://localhost:8000 を開く
```

> 音楽は最初のクリックで始まります（ブラウザの自動再生ポリシーのため）。
